Hey Guys!

For everyone familiar with Unity then you guys know how the shebang goes with imported packages and such lol

For everyone whose NOT familiar, I just wanna make some ground rules very clear here as far as the project moves forward.

**BACKEND**
- PLEASEEEE COMMENT ON EVERY FUNCTION AND LINE OF CODE(doesn't need to be every single line just please document every thought process you've had)
   - crucial for easy bug fixing and you'll thank me later 
   - makes it easier for people to add onto your scripts

**FRONTEND**
- Whenever you wish to add a new object just add it into the respective asset group as you will see later on
- If you're creating a new custom level, make sure to BOTH make your own branch in the GitHub and ONLY work there, as well as make a BRAND NEW scene and ONLY work there too, it'll make merge conflicts almost nonexistent as far as level designing is concerned.

**UI**
-Please follow the tips in the UI channel on the discord and make sure to follow through with the UI manager as Lucas had advised
